<!-- ───────────────── 1. IntelliViz ───────────────── -->
### 🤖 [IntelliViz](https://github.com/fewgets/IntelliViz-FYP): AI Industrial Monitoring & Predictive Maintenance
`Final Year Project` · `NUML Islamabad` · `2026`

An end-to-end industrial intelligence platform that monitors a fleet of machines in real time,
**predicts when and why a machine will fail**, schedules maintenance, and lets plant staff
**ask questions about their data in plain English** through **Orion AI**.

| | Highlights |
|:-:|---|
| 🧠 | **Multi-task LSTM** predicts remaining useful life, failure within 24 h and fault type: **99.2% failure accuracy, 98.3% fault-type accuracy** |
| 🤖 | **Orion AI:** a LangGraph pipeline of 6 agents (orchestrator → cleaner → analyst → visualizer → validator → domain expert) that checks every number before answering |
| 📡 | Live telemetry streams, anomaly drill-down, health bands and maintenance work orders |
| 🛡️ | Role-based auth, prompt-injection guardrails, Gemini → Mistral fallback, 35+ test modules, Docker Compose |

### 📞 [CallSynt](https://github.com/fewgets/CallSynt): Self-Hosted AI Voice Agents
`In Development` · `DevSynt` · `2026`

A configurable voice-agent platform that **answers and makes business phone calls**: booking
appointments, answering FAQs and qualifying leads, all on an **open-source, self-hosted voice stack**.

| | Highlights |
|:-:|---|
| 🎙️ | Real-time pipeline: LiveKit → Silero VAD → faster-whisper → local LLM (Ollama) → Kokoro TTS |
| 🏢 | Multi-tenant agent builder with versioned settings, a RAG knowledge base (pgvector) and business tool connectors |
| 📤 | Inbound routing and outbound campaigns with consent checks, opt-outs and retry limits |
| ✅ | Call QA with outcome evidence, a human review queue and a target of p95 latency under 2 s |
